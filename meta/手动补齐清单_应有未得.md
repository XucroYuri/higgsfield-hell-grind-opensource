### 手动补齐时放哪里？

1. 在浏览器打开失败 URL，能下则保存。  
2. 从 URL 或页面识别 **job_id**（UUID）与是 output / thumbnail / reference。  
3. 在 `folders/` 内搜该 `job_id`：

```bash
# 示例：找 job 应落在哪
find folders -type d -name '<job_id>'
```

4. 按类型放入：

| 媒体类型 | **放入位置** |
|----------|----------------|
| 主结果视频/图 | `folders/<场次路径>/Assets/outputs/<job_id>/output.mp4`（或官网扩展名 `.png` 等） |
| 结果缩略图 | `…/Assets/outputs/<job_id>/thumbnail.webp` **或** `…/Assets/thumbnails/<job_id>.webp`（与邻接文件一致即可） |
| 提示词参考素材 | `…/Assets/references/`（文件名尽量保留源文件名） |

5. 可选：同时拷一份进 `_media_blobs/` 并硬链（与现有策略一致）；若只补 Assets 文件也可。  
6. 场次路径以 **rename 后官方名** 为准（如 `folders/Hell Grind/Scene 26/…`），不要用旧的 `Name__hash`。

**若无法从 URL 还原 job_id**：在 `meta/manual_inbox/` 建目录，文件命名带原 URL 哈希，再人工对照 `media_manifest.json` 归位：

```text
meta/manual_inbox/
  README.txt          # 你写下来源 URL
  <原文件名或 hash>.mp4
```
