# 源仓下载校验说明

## 脚本

| 脚本 | 作用 |
|------|------|
| `scripts/validate_source_download.py` | 按 media_manifest 核对 Assets 是否漏下/空文件/路径不符 |
| `scripts/validate_source_structure.py` | folder.json / job_sets / prompts / mapping 结构抽查 |

## 用法

```bash
cd higgsfield-hell-grind-opensource

# 下载过程中可抽查
python3 scripts/validate_source_download.py --sample 20

# 下载完成后全量
python3 scripts/validate_source_download.py

# 命名后处理后再跑一次（路径会变）
python3 scripts/validate_source_download.py --strict
python3 scripts/validate_source_structure.py
```

## 通过标准（收尾）

- `missing_files == 0`
- `empty_files == 0`
- `folders_with_issues == 0`（或仅记录已知 S3 级例外并文档化）
- mapping 存在且无悬空路径
- 无自创消歧目录名启发式命中

## 报告

- `meta/download_validation_report.json` / `.md`
- `meta/structure_validation_report.json`
