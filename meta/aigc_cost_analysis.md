## 3. 生成 / 采纳（镜头级代理指标）

导出数据**没有**「最终成片选用」标记（`is_favourite` / `published_at` 基本为空）。

采用可计算代理：

1. **变体采纳率** = 1 / (该 job_set 的 jobs 数) — 假设每批次最终只用 1 条  

2. **场景迭代强度** = 该文件夹 jobs / job_sets  

3. **完成率** = completed / all（本库 jobs 状态几乎全是 completed）  


- 全局平均变体采纳率：**46.8%** → 平均约 **3.00 次生成换 1 次采纳**  

- jobs/job_set 分布：`{1: 10083, 2: 1577, 3: 5076, 4: 21746}`  

- 最常见：4 变体批次（21,746 个 job_set）→ 采纳率 25%  

- 单变体批次：10,083 个 job_set → 采纳率 100%（无同批落选）

## 4. 成本假设与方法

详见 JSON `cost_assumptions`。要点：

- 1 credit ≈ **$0.0431**（由 Seedance 720p/8s/$1.55/36cr 反推）  

- Seedance：按 duration/resolution/mode 相对 8s@720p 线性缩放 × 批内 job 数  

- 图像模型：固定 credits/job 表  

- 稀疏 `job_set.cost`：经验式 `credits ≈ cost/1000`，与 1080p 下 `900*dur*n_jobs` 一致  


## 5. 风险与后续可挖

1. 成片时间线（final edit）对齐 → 真·采纳率  

2. 企业价/无限套餐会显著低于本报告  

3. 参考图张数、音频、多镜头 `multi_shots` 可能加价（未全计入）  

4. 与 `media_download_progress` 交叉：下载成功/失败 URL vs job 结果
