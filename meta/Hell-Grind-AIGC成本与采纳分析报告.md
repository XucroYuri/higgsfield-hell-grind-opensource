## 二、数据范围与方法

### 2.1 数据源

| 来源 | 说明 |
|------|------|
| `folders/**/job_sets.json` | 全量批调用与 jobs（分析时跳过 `Assets/`） |
| 扫描结果 | 159 个含 job_sets 的目录节点 |
| 字段 | `type` / `params`（model、duration、resolution、mode…）/ `jobs[]` / 稀疏 `cost` |
| 未使用 | 成片时间线、真实账单、企业合同价 |

### 2.2 成本模型

1. **公开锚定**（Higgsfield 2026 公开材料）：Seedance 2.0 Standard **720p / 8s ≈ 36 credits ≈ $1.55**  
   → **1 credit ≈ $0.0431**  
2. **Seedance 推算**：  
   `credits ≈ 36 × (duration/8) × 分辨率系数 × 批内 job 数`  
   - 分辨率系数：480p 0.7 / 720p 1.0 / **1080p 1.5** / 4K 2.5  
   - mode=fast/mini 时改用 Fast 锚定 28 cr @720p/8s  
3. **图像等模型**：按类型固定 credits/条（Nano≈2、Soul≈3、GPT Image≈4 等，见 JSON `flat_credits_by_type`）  
4. **稀疏平台 cost**：经验式 `credits ≈ cost/1000`（与 1080p 样本 `cost ≈ 900×秒×条数` 一致）  
5. **人民币**：`CNY = USD × 6.75`

### 2.3 采纳率定义（代理指标）

导出**无**「最终成片选用」字段（`is_favourite` / `published_at` 基本为空）。本报告采用：

| 代理 | 定义 |
|------|------|
| **变体采纳率** | `1 / n_jobs`（同一 job_set 内假设只保留 1 条） |
| **迭代强度** | 文件夹内 `jobs / job_sets` |
| **完成率** | `status==completed` 占比（本库接近 100%） |

## 七、局限与后续

1. **非账单**：`cost` 几乎为空；Unlimited/企业价未建模。  
2. **真·成片采纳**需剪辑时间线或人工标注，方可替换「批内取 1」假设。  
3. 参考图数量、音频、`multi_shots` 等加价项未完全计入。  
4. 可与 `media_download_progress` 交叉：下载失败 URL 是否对应付费生成。  
5. 复跑：  
   `python3 scripts/analyze_aigc_cost_and_adoption.py`  
   然后可再运行本报告生成逻辑或直接更新本文件。
