# 翻译原则

## 1. 目标质量

汉化成果必须同时满足：

| 维度 | 要求 |
|------|------|
| **完整** | 约定范围内的文本资产均有对应译文或明确「保留原文」策略 |
| **准确** | 术语与源字段、电影/制作语义一致 |
| **可验证** | 任意译文可抽检回源；有校对记录与版本号 |
| **可对照** | 服务 know-how，减少研究时临时英译汉 |

不是「流畅优先」的文学意译优先，而是 **技术档案忠实优先**。

---

## 2. 翻译范围（Scope）

### 2.1 必须翻译（全量阶段）

- `brief/` 项目 Brief 与说明类 Markdown  
- 治理可见的说明文档（本仓自产文档除外已是中文）  
- 结构化元数据中的**人类可读描述字段**（若有 `description` 等）  
- 提示词中的**可叙述正文**的中文对照层（见 §4）  
- 技能文件（CINEDANCE / ACTING / LIRA）若源仓取得  

### 2.2 默认不翻译（保留原文）

- 文件夹官方 `name`（如 `Scene 26`、`Regenerations`）——与源一致  
- `folder_id` / `job_set_id` / `job_id` / URL  
- job `type` 字面量：`seedance_2_0`、`gpt_image_2`…  
- JSON **键名**  
- 文件哈希、blob 路径、技术底座中作为**固定咒语**的专有名词行（可在术语表给释义，正文可保留英文行 + 注释）  

### 2.3 媒体

- 默认不复制 mp4/png 到本仓  
- `content/` 中用清单记录：`source_media_path` → 可选 `caption_zh`  

---

## 3. 忠实层级

| 层级 | 适用 | 做法 |
|------|------|------|
| L1 字面忠实 | 参数说明、规则、禁令、技术底座 | 直译 + 术语表 |
| L2 功能忠实 | 镜头 action / 叙事描写 | 准确传达动作、空间、光、表演，不美化剧情 |
| L3 对照注释 | 难词、双关、专有声线描述 | 译文 + `〔注〕` 简短说明 |

**禁止**：为「更好懂」改写官方规则强度（如删掉 NEVER/ONLY 类硬禁令的力度）。

## 4. Prompt 汉化策略（强制）

对每条 `params.prompt`（及 `prompts/*.txt` 等导出正文）：

### 落盘位置（强制 · 并排）

**必须**写在源文件同目录，命名 `源stem.zh.md`，例如：

```text
folders/.../prompts/00002_<job_set_id>.txt      # 源，勿改
folders/.../prompts/00002_<job_set_id>.zh.md    # 汉化，并排
```

**禁止**仅把译文放在独立中文目录树而源旁无文件。  
详见 [`并排双语落盘规范.md`](./并排双语落盘规范.md)。

### 推荐文件形态

```markdown
# prompt 对照 — job_set_id: <uuid>

## 元数据
- source_path: folders/.../prompts/00002_<id>.txt
- job_type: seedance_2_0
- folder_official_name: Scene 26
- translation_status: draft | reviewed | approved

## 原文 (source)
```
...原文全文...
```

## 中文对照 (zh)
```
...中文全文...
```

## 段落对齐备注（可选）
- GEO: …
- KEY RULES: …
```

### 规则

1. **原文块不可删**  
2. 中文块与原文块一一对应；重大结构标题保留英文原题并附中文：  
   `## GEOMETRY（空间几何 / 站位）`  
3. `@roco` 等标签 **不翻译**  
4. 技术底座 12 行：可逐行「英文原句 + 中文释义」，或整段对照；须进术语表的词统一  

---

## 5. 术语纪律

1. 凡重复出现 ≥2 次的制作/模型概念，必须进 `01-术语表/受控词表.md`  
2. 一词一条；**英文键唯一**  
3. 弃用译法写入「禁止使用」列  
4. know-how 研究禁止另造译名（应 PR/提案改术语表）  

---

## 6. 版本与溯源

- 源快照：记录 opensource 的 git commit + 映射文件哈希 + 下载完成日  
- 译文版本：`v主.次.修订`（见 `00-治理/版本策略.md`）  
- 每次发布：`07-对照索引/release-notes-zh.md`  

---

## 7. 与「意译」「本地化润色」的边界

| 允许 | 禁止 |
|------|------|
| 通顺的中文语序 | 弱化/删除官方硬约束 |
| 固定专业译名 | 同一概念多种中文并存 |
| 对文化指称加〔注〕 | 把角色名擅自改成中文名（除非术语表批准） |
| 保留官方文件夹英文名 | 把 `Scene 26` 改成「第二十六场」作为目录名 |
