# 重资产映射策略（禁止二次下载）

## 1. 原则

| 原则 | 说明 |
|------|------|
| **只下一份** | 视频/图片/缩略图等重资产**仅在源仓**下载与存储 |
| **汉化层不抓网** | `zh/` **禁止**再对 CDN/API 拉同一 URL |
| **位置对应** | `zh/content/` 内路径与仓根 `storage_path` **镜像对齐** |
| **优先硬链接** | 同卷优先 `os.link` / `cp -al`；失败再符号链接；最后才复制 |

## 2. 路径对应

源仓（权威二进制）：

```text
higgsfield-hell-grind-opensource/folders/<storage>/Assets/outputs/<job_id>/output.mp4
```

汉化层（映射，不重复占带宽）：

```text
higgsfield-hell-grind-opensource/zh/content/folders/<storage>/Assets/outputs/<job_id>/output.mp4
  → 硬链接/符号链接到上述源文件（同仓同卷）
```

文本汉化（**主路径 = 源旁并排**，见 `并排双语落盘规范.md`）：

```text
folders/<storage>/prompts/00001_<job_set_id>.txt      # 源
folders/<storage>/prompts/00001_<job_set_id>.zh.md    # 汉化并排（强制主落点）
```

`zh/content/` 仅可选工具镜像，**不能替代**源旁 `.zh.md`。

## 3. 映射作业时机

1. 原文镜像下载完成  
2. 命名后处理完成（`meta/id_path_mapping.json`）  
3. 校验通过（`scripts/validate_source_download.py`）  
4. 再执行 `zh/03-工具与脚本/link_media_from_source.py`

## 4. 记录

`zh/07-对照索引/media_link_manifest.jsonl` 每行：

```json
{
  "source_path": "folders/.../Assets/outputs/.../output.mp4",
  "zh_path": "content/folders/.../Assets/outputs/.../output.mp4",
  "link_type": "hardlink|symlink|copy",
  "source_sha256": "…",
  "status": "ok|missing_source|error"
}
```

## 5. 禁止

- 在 `zh/` 内 `curl`/`wget` 源 CDN  
- 在 `zh/content` 另建无对照的 Assets 树  
- 改仓根二进制以「适配中文」
