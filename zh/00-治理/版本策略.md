# 版本策略

## 1. 双版本号

| 版本 | 含义 |
|------|------|
| `source_ref` | 对应官方镜像状态：opensource git commit + `id_path_mapping` 摘要 |
| `zh_release` | 汉化发布：`vMAJOR.MINOR.PATCH` |

示例：

```yaml
source_ref:
  opensource_commit: "9638126"
  mapping_file: "meta/id_path_mapping.json"
  mapping_sha256: "…"
  noted_at: "2026-…"
zh_release: "v0.1.0"
```

## 2. 语义化规则（zh_release）

| 变更 | 升级 |
|------|------|
| 试点通过、流程冻结 | v0.1.0 |
| 大批量译文新增（范围扩大） | MINOR |
| 术语表破坏性统一（大量旧译作废） | MAJOR |
| 错译修正、错别字 | PATCH |

## 3. 状态机（单文件/单 prompt）

`untranslated → draft → reviewed → approved → (stale)`

- `stale`：源仓同路径内容变更后，译文过期，须重译  
- 发布进「稳定对照」仅收 `approved`  

## 4. 发布物

每次 `zh_release` 至少包含：

- 术语表版本钉扎  
- 对照索引导出  
- 抽检报告摘要  
- source_ref
