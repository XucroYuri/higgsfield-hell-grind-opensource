# 与源仓对齐规则

## 1. 路径镜像原则

汉化 `content/` 的相对路径应能映射回源仓：

```text
源:  higgsfield-hell-grind-opensource/folders/<storage>/prompts/00001_<job_set_id>.txt
中:  content/folders/<storage>/prompts/00001_<job_set_id>.zh.md
```

- `<storage>` 与源仓物理目录名一致（官方 name 或冲突时的 folder_id）  
- **不**为中文另造场次目录名  

## 2. 一对多/一对一

| 源对象 | 汉化对象 |
|--------|----------|
| 一个 Brief.md | `content/brief/….zh.md`（内含原文或链到源） |
| 一个 prompt txt | 一个对照 md（原文+中文） |
| 一个 folder.json | 可选 `folder.zh.json` 仅译 description 等；`name`/`id` 不动 |

## 3. 源变更检测

源文件 hash 变化 → 对照索引标记 `stale` → 进入重译队列。  
脚本预留：`03-工具与脚本/check_source_drift.py`（源就绪后实现）。

## 4. 权威顺序（争议时）

1. 源仓原文  
2. 本仓 `approved` 译文  
3. 术语表  
4. know-how 研究表述（可错，须回修）
