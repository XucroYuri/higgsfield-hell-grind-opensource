# AGENTS.md — 汉化工作（并排双语）

## 最重要

**每一个视频生成任务**的源 prompt / 设计描述，必须在**同一目录旁**有一份汉化文档（`.zh.md`）。

- ✅ `folders/.../prompts/00002_<id>.txt` + **`00002_<id>.zh.md`**  
- ❌ 只在单独中文目录树里放译文、源旁没有文件  
- ❌ 改写或覆盖源 `.txt` / 官方 JSON 里的原文  

**源仓目录结构仍按原计划**：`folders/` 官方名、`Assets/`、`job_sets.json`、`prompts/` 命名规则不变。

完整规范：[`00-治理/并排双语落盘规范.md`](./00-治理/并排双语落盘规范.md)

## `zh/` 本层职责

本目录只放：**治理、术语、流程、质检、工具、进度**——不是第二套 Scene 树。

| 写哪里 | 内容 |
|--------|------|
| **源树并排** `folders/...` / `brief/...` | 每条 prompt / 设计说明的 `.zh.md` |
| **`zh/`** | 词表、译校流程、抽检、索引、脚本 |

## 硬约束

1. **原文只读（语义）** — 不改官方 name、prompt 原文、job 参数、媒体  
2. **并排可回溯** — `.zh.md` 含 `source_path` / `job_set_id` / `job_type`  
3. **术语受控** — `01-术语表/受控词表.md`  
4. **中英锚定** — 字段名/type/路径保留英文；叙述中文  
5. **媒体** — 禁止二次下载；二进制权威在仓根 Assets / `_media_blobs`  
6. **旧路径** — `opensource-Chinese/` 已废弃；勿再往独立中文仓写译文  

## 与 know-how

- 取证 → 仓根原文  
- 定稿中文 → **并排 `.zh.md`**（及本层词表）
