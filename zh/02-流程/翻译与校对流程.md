# 翻译与校对流程

## 总览

```
源就绪门禁
    │
    ▼
构建待译清单 (inventory)
    │
    ▼
术语表冻结 (glossary freeze)
    │
    ▼
试点 (pilot) ──失败──► 修原则/术语/工具
    │ 通过
    ▼
全量分片翻译 (draft)
    │
    ▼
校对 (reviewed)  ← 交叉校对 / 第二 Agent
    │
    ▼
抽检 (QA sample)
    │
    ▼
发布 (approved → zh_release)
    │
    ▼
供 know-how 引用
```

---

## 阶段 A — 清单

输入：opensource 树 + mapping  

输出：`06-全量作业/inventory.jsonl` 每行：

```json
{
  "id": "…",
  "source_path": "…",
  "kind": "brief|prompt|meta|skill|other",
  "job_set_id": null,
  "priority": 1,
  "status": "untranslated"
}
```

优先级建议：

1. Brief 全文  
2. 技术底座/高频规则句  
3. Assets 相关 descriptor（若有）  
4. 各场最长 seedance prompt（试点同源）  
5. 其余 prompt 按场次批处理  

---

## 阶段 B — 翻译（draft）

角色：翻译 Agent / 译者  

检查表：

- [ ] 已查受控词表  
- [ ] 英文键/标签未误译  
- [ ] 硬禁令力度保留  
- [ ] prompt 含原文块 + 中文块  
- [ ] 填写 `translation_status: draft`  
- [ ] 更新对照索引  

---

## 阶段 C — 校对（reviewed）

角色：**不得与译者同一 Agent 会话无审查**（第二 Agent 或人类）

校对维度：

| 码 | 维度 | 说明 |
|----|------|------|
| T | 术语 | 与词表一致 |
| F | 忠实 | 无削弱/添戏 |
| S | 结构 | 段落/GEO/RULES 对齐 |
| L | 标签 | @tag、type、id 未改 |
| R | 可读 | 中文通顺但不牺牲准确 |

状态：`draft → reviewed`，记录校对者与日期。

---

## 阶段 D — 抽检（QA）

- 随机 + 风险分层（最长 prompt、含中英混排、Regenerations）  
- 样本率：试点 100%；全量建议 ≥2% 或每场至少 1 条  
- 缺陷分级见 `04-质检/缺陷等级.md`  
- 致命缺陷 → 阻断发布，退回批次  

---

## 阶段 E — 发布

- 仅 `approved` 进入「know-how 默认可引用」集合  
- 打 `zh_release` 标签  
- 写出 `source_ref`  

---

## Agent 编排建议

| 角色 | 职责 |
|------|------|
| 清单员 | inventory |
| 译员 | draft |
| 校对员 | reviewed（独立） |
| 质检员 | 抽检与统计 |
| 发布员 | 版本与索引冻结 |
