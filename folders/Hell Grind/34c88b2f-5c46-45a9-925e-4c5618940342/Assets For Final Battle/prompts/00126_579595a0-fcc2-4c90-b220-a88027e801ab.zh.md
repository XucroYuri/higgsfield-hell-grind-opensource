## 原文 (source)

Edit this winter landscape image. Change the camera angle from 
frontal view to a three-quarter angle perspective view of the same 
exact location, preserving every element of the scene with maximum 
fidelity.

CAMERA ANGLE CHANGE:
The current image is a frontal view of the location. Reframe the 
same exact scene as if the camera moved approximately 30-40 degrees 
to the side, now viewing the location from a three-quarter angle 
perspective — the side and front of the scene visible together, 
the tree seen from the three-quarter angle showing both its front 
profile and side profile simultaneously, depth and dimension reading 
through the parallax shift, the spatial relationships between 
foreground rocks, midground tree, and background visible from the 
new angle.

PRESERVE ALL ELEMENTS WITH MAXIMUM FIDELITY:

THE TREE — preserve every detail:
The same exact gnarled twisted tree with the same dark weathered 
bark texture, same exact branch structure and silhouette (just seen 
from the new angle), same dried red leaves clinging to the branches 
in the same density and distribution, same low spreading wind-
shaped canopy, same exposed gnarled root system at the base, same 
trunk thickness and twisted character, same overall shape and scale. 
Every branch and root preserved, just viewed from three-quarter 
angle. The tree is the central subject in the new angle, positioned 
naturally in the reframed composition.

THE GROUND AND FOREGROUND — preserve every element:
The same scattered rock formations on the plateau, the same dried 
red bushes with their distinctive scraggly shape, the same pale 
ornamental grasses with feathery seedheads, the same deep clean 
white snow with the same texture and drift patterns, all the same 
small vegetation details. Reposition naturally in the three-quarter 
angle composition but preserve every element.

THE BACKGROUND AND ATMOSPHERE:
Same dense atmospheric haze and fog, same depth fade into the 
distance, same overcast pale grey-blue sky with subtle cloud 
texture, same atmospheric mood and quality, same light direction 
preserved in the new angle. Falling snow particles preserved.

LIGHTING AND COLOR:
Same exact light quality, same diffuse cool overcast lighting, same 
cold winter palette, same color grade with cool blue-grey tones and 
subtle dried red accents in the vegetation, same contrast level, 
same exposure. The lighting on the tree and ground naturally 
adjusts to the new viewing angle but the overall lighting recipe 
stays identical.

PHOTOGRAPHIC QUALITY:
Same exact film grain texture, same photographic quality, same 
cinematic aesthetic, same anamorphic film still character.

PRESERVE EXACTLY:
— Every element of the scene, just from a different angle
— The tree identity, structure, branches, leaves, roots, bark
— All foreground vegetation, rocks, bushes, grasses
— Snow texture, drift patterns, accumulation
— Atmospheric haze and fog density
— Sky, clouds, mood
— Lighting direction and quality
— Color grade and palette
— Film grain and photographic texture
— Cinematic widescreen aspect ratio
— No new elements introduced
— No phantom shapes or hallucinated detail in the haze
— No different tree, no different vegetation, no different rocks

The result: same exact winter plateau location with the same exact 
tree, vegetation, rocks, snow, atmosphere, sky, lighting, and 
photographic quality, but viewed from a three-quarter angle instead 
of frontal. Every element preserved, only the viewing angle 
changed.

Photorealistic, real practical location photography, ARRI Alexa 
anamorphic film still aesthetic. Match the texture, grain, color 
grade, and lighting quality of the input image exactly. Same 
location, three-quarter angle view, every element preserved. Not 
CGI, not stylized, not a different tree, not a different location, 
not a regeneration from scratch, just a reframe to three-quarter 
angle of the same exact scene.
