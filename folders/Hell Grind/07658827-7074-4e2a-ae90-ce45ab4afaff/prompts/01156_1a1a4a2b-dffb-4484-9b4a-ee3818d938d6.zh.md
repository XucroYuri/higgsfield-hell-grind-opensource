⚠ 真实弹道学 (ballistics — 精确规格, 每帧可见地应用):

子弹本身:
- 弹种 (cartridge): 重型远程步枪弹 — 等效.50 BMG (12.7×99mm)。弹丸质量 ≈ 45g。长度 ≈ 58mm。直径 ≈ 12.7mm。FMJ 铜套, 铅芯。Ogive 鼻部, boattail 后部。
- 冲击时速度: ≈ 750 m/s — 马赫 2.2, 在冷暴风雪空气中坚定地超音速。
- 自旋: ≈ 270000 RPM 顺时针绕长轴 (1-in-15-inch 膛线扭转)。在 10000 fps 慢动作下旋转可见地缓慢 — 膛线痕迹绕剪影在多帧中转动。
- 冲击时动能: ≈ 17000 焦耳 — 足以连续击败一个木杆、一个薄铁面具、一个颅骨、一个 kabuto 后板, 以及 3-4 个额外的头盔头部对。

子弹在空气中留下的: 一个微弱的圆锥 SUPERSONIC VAPOR CONE (Prandtl-Glauert 效应) 从鼻部向后拖尾, 半角 ~25-30°。在湿暴风雪空气中, 它短暂地凝结为子弹身后的薄白色蒸汽 wisps。垂直冲击波 (shockwave) 从子弹辐射出去, 瞬间将雪花推向轨迹周围的薄压力波光环外 — 子弹周围短暂打开一个清晰的空气管道, 通过后被推开的雪卷回来。无 tracer glow, 无 muzzle flash 可见 — 源在远处雾中。

轨迹 (trajectory, 强制): 从帧 0 到最后一次冲击, 严格直线。在此距离没有可见下落, 没有弯曲。轨迹与: 切断长矛杆冲击点 → 将军面具中心 → 将军颅骨 → 将军 kabuto 后部 → 然后继续进入后部人潮 — 共线锁定。

子弹偏航与翻滚 (yaw & tumble, 随着子弹击败连续材料而变得可见): 木后偏航 ~1-2°, 重新稳定在几厘米内; 面具后 ~2-4°; 颅骨前额后保持轻微; 颅骨后 + kabuto 后 ~3-5° (子弹可见地略微偏离轨迹线); 3-4 个后续僵尸头部后 ~10-15° 并开始翻滚 (其长轴绕轨迹线进动, 剪影可见地端对端翻滚)。

⚠ PENETRATION PHYSICS — 按顺序对每种材料的精确效果 (压缩):
(1) 木杆 (3-4cm 硬木): 短暂的圆顶压缩, 然后失败; 长锯齿状碎片在入口处向后剥离, 在出口处向前飞; 锯末和树皮云; 杆干净地切断为两半, 带有小的旋转踢; ~1-2% 能量损失; ~1-2° 偏航, 然后重新稳定。
(2) 铁 menpo 面具 (2-3mm 锈蚀): 冲击点向内凹陷成一个小凹陷, 锈粉的光环脱落; 子弹直径的圆形铁塞向内冲, 边缘在子弹穿过时向后剥离; 脆铁向外径向裂缝裂开 — 面具碎裂成多个锯齿状铁片 (一些剥落 / 弯曲, 一些断裂并缓慢翻滚); 从铜对铁摩擦的明亮橙色火花阵雨; 面具绳索 / 皮带松动或断裂, 面具从安装架倾斜; ~3-5% 损失; +1-2° 偏航。
(3) 颅骨前额 (5-7mm 脆古老骨头, 部分木乃伊化): 跨前额的细发裂纹星爆; 灾难性粉碎 — 小骨塞向内推, 周围前额骨在锯齿状碎片锥中向外爆裂; 喷出物 = 骨碎片 + 绿色苔藓 + 黑色霉菌 + 战场污垢 + 干燥灰色腐肉条; 骨灰光环; ~2-3% 损失; 轻微偏航。
(4) 颅骨腔: 隐藏在颅骨内的小白蛆虫被压力波喷出 — 它们扭动并通过两个洞翻滚出来, 从镜头边失焦闪过。
(5) 颅骨后 (相同脆骨): 与前额相同 — 星爆 → 灾难性粉碎 → 骨头 + 苔藓 + 霉菌 + 污垢的向前爆裂; 骨灰光环; ~2-3% 损失。
(6) Kabuto 后铁板 (~3mm 锈铁): 与 menpo 面具相同 — 凹陷 → 失败 → 裂缝 → 向前火花阵雨; kabuto 因出口冲击波 (shockwave) 向前倾斜跳动; ~3-4% 损失; 累积偏航 ~3-5°。
(7) 后续僵尸头盔头部对 (每个 = kabuto 后板 → 颅骨后 → 腔 → 颅骨前 → kabuto 前板, 全部按上述物理): 每整对花费子弹 ~7-10% 能量并增加偏航。到第 4 个头: 偏航 ~10-15°, 子弹可见地端对端翻滚同时仍向前移动。
(8) 平行机枪弹 (在 7.5s 揭示): 每个是独立的.50 BMG 具有相同弹道学概况, 以毫弧度发散发射 (在此距离 ~30-50cm 横向间距) — 可见为多个平行条纹, 每个按上述相同物理击败自己的目标线。
