开局例外（仅本提示词）：（a）在第 0 帧，三具单独的僵尸（/ 混合）从环线中踏出，逐个进入竞技场进犯 Roco——每一个都冲上前，被斩，瞬间成灰，然后下一个踏出；第三个之后不再有出的。环线其余部分保持立定。被击中时，僵尸的身体沿切口崩解成一股黑色飞灰（干燥暗色颗粒——无火、无光、无血污、无烟）；身甲／刀／长枪在身体消失时落于雪地。（b）就在第三股飞灰散开同一节拍，<<<1a2f4529-b84a-4109-ab06-51d53bd61402>>>1 从外侧破开东线——从深尸潮中碾过自己的军队，把僵尸们狠狠撞开；一旦进入场内，被撞散的身体又回垂成一条闭合的尸线，环在决斗余下部分保持静止。

摄像机——动态规则集（DYNAMIC RULESET）（每一帧）：1. 地平线倾斜必须有物理动机——绝非风格化。每一次荷兰角（5–25°）都是一次惯性（操作员手持甩摇/环绕/下坠/奔跑会把云台甩向运动方向偏线）或冲击震动（规则 #4）的后果。倾斜随操作员身体出现并缓慢回正。绝无两次剪接采用相同倾斜。
2. 主角绝不居中。构图落在极端的九宫格或边缘——脸在画幅外侧 1/6，视线引导向外偏出画幅，大量负空间填满雪／雾／旗帜／虚焦僵尸／枪杆。
3. 硬剪接上激进的换镜头（LENS-MIXING）。每一次剪接都猛然切到完全不同的焦距（14mm / 24–35mm / 50mm / 85mm / 135mm / 微距 macro），常与预期相悖。结合下方 #6：每一次剪接也都改变主体体量（WS/MS/CU 远景/中景/特写）并改变 ≥30° 角度。
4. 每一次冲击都有反应性震动（REACTIVE VIBRATION）——幅度随力度缩放。轻击（脚步、小飞灰迸发）= 1 帧抖动约 2–4 厘米 + 倾斜抽搐。重击（交锋、腹锤、拍击、身体冲撞、剑插地）= 10–20 厘米镜头踩踏（lens-stomp）+ 0.2–0.5 秒内 3–5 次衰减副震荡，荷兰角朝冲击方向甩出、随后缓慢回正。可随后接 0.2–0.4 秒慢镜头冲击定格（slow-mo shock-hold）再猛然回弹。每一次震荡都是观众感知力量的标尺。
5. 摄像机始终运动——手持呼吸抖动，加上无人机式 180–360° 环绕、吊臂甩摆、地面轨道跟拍、穿过前排僵尸的视差推近（parallax push-in）、180–720° 甩摇、急推变焦（snap-zoom）、焦点拉移（rack-focus）、镜头踩踏。几乎每一帧都有前景遮挡物（雪涡、旗帜、枪杆、虚焦僵尸、镜头上的雪花）。绝无静态镜头。
6. 剪辑纪律（EDIT-CUTTING DISCIPLINE）：剪接严格交替镜头体量（WS/MS/CU）并改变焦距并改变 ≥30° 角度。单一节拍内遵守 180° 动作轴线。可行时在动作上做匹配剪（match-cut）（挥剑 / 倒地 / 喷灰 / 落脚）。速度渐变（speed ramps）：标志性节拍上 0.2–0.5 秒慢镜头爆发，跟手时猛然回弹到实时。
镜头：14mm 超广角低机位（破环 THE BREACH、地面级广角、前景僵尸视差）· 24–35mm 广角中景 MS（奔跑覆盖、拍击轨迹）· 50mm 紧凑中景 MS（僵持、对招）· 85mm 紧凑 + 微距特写 CU（指节接触、刀刃末端材质、裂纹与重生、视线节拍）· 135mm 长焦压缩（冲刺逼近被压平、刀刃末端在顶点被拉入镜、雪花在平层中堆叠）。

动作节拍——不停顿、不等待；场景一开始就已处在运动中。序列由恰好 6 个硬切镜头（HARD-CUT SHOTS）组成——在每一镜内，摄像机以镜内运动（in-camera moves）完成急推变焦、推近、环绕运动、慢镜头冲拳式推进、微距冲拳式推进，而非作为独立的硬切。剪接严格交替镜头体量（WS/MS/CU）和焦距，每次剪接角度变化 ≥30°。每一镜都在其自己的“背景”段（BACKGROUND）小段落中明确描述背景僵尸们在做什么。

镜头 1 —— 0.0–6.0 秒 —— 僵尸波（THE ZOMBIE WAVE）〔开场为 Roco 的紧特写——第 0 帧 85mm 极限紧特写 → 镜内操作员后退、拉出到 50mm 中景 → 猛然回切 35mm 广角 → 甩摇到 24mm 广角，荷兰角自 +13° 起步、随操作员惯性漂移〕：第 0 帧摄像机正对着 <<<1d58fa3e-7359-4376-bb67-ea43d20c8fdb>>> 的脸——一个 85mm 极限紧特写，在竞技场正中央框住他的头盔透视窗与持剑之肩，剑握在右手，正处于半弧中。第一具僵尸的身体（）就在他透视窗前极近的前景中，在 Roco 自上斜切的刀刃从他身上贯穿而过时，砰然爆成飞灰——暗色晶体刀身掠过画幅下三分之一，飞灰颗粒对着暗色透视窗喷涌而出，身甲（kabuto）头盔从镜头前翻滚而过。头盔透视窗 + 飞灰云在第 0 帧以极限紧细节占据主导。三具僵尸击杀在同一个连续手持镜头中完成，镜头随着拍摄推进逐步拉宽：
— 第一次击杀（第 0 帧 85mm 特写 CU）：Roco 正从一个从后脚顺时针旋转的枢转中旋转，刀弧完成一道自髋到冲来僵尸对侧肩的自下斜切。僵尸沿切口瞬间崩解成一股浓密的细黑灰——干燥暗色颗粒向外喷溅，恰好从 Roco 透视窗旁散入暴风雪；身甲头盔、胸甲碎片、脱手的刀在身体消失时落于雪地。摄像机在切口处做出反应性抖动。操作员向后跨步，镜头猛然拉宽到 50mm 中景。
— 第二次击杀（50mm 中景 MS）：当 Roco 完成旋转时，第二个已从西南线踏出，正从镜头左侧持枪冲刺入画。Roco 旋身转入枪击之内，沉低身形，以髋部高度一道低平横弧挥出 <<<e396547e-df91-4ae5-b2b7-b730eb86f7b3>>>。切口在腰际截住僵尸——下身瞬间成灰，上半躯干在空中悬停一瞬随即也爆成灰，长枪从灰云中端对端翻滚坠落，磕落在冰上。摄像机反应性抖动，随后顺时针 110° 甩摇横扫竞技场（荷兰角因甩摇惯性过冲从 +9° 猛地趔到 -4°），镜头猛然拉宽到 35mm。
— 第三次击杀——贯穿（35mm 广角）：第三个从东线现身，高举一柄长刀。正当他挥下这一劈时，Roco 跨步闪入刀圈之内，以直线攻击把 <<<e396547e-df91-4ae5-b2b7-b730eb86f7b3>>> 于胸骨高度猛地刺穿胸腔。镜内急推变焦到贯穿处的 85mm 微距特写（0.3 秒慢镜头）：暗色晶剑剑尖穿入而出，飞灰向外喷溅，构图偏于右下。猛然回弹到实时并拉出到 24mm 广角。僵尸痉挛，随即从伤口向外瞬间成灰，凝成一股从剑尖喷发的柱状灰；刀坠落，身甲翻滚。贯穿处出现 8 厘米离轴镜头踩踏。

本镜背景：第 0 帧紧特写主要显示透视窗 + 飞灰云——只有最近的尸环在深处背景以失焦暗剪影（带节奏性上扬的枪杆）隐约可见。随着镜头在拍摄中不断拉宽，完整尸环进入画幅，显出基线行为——战鼓敲击、枪杆高扬、未亡之颚嘶着气雾、旗帜在 30–45° 阵风中嘎地拉直、外围骑兵跺着骨蹄。在三次飞灰迸发的每一次，前排都会骤然提速——一圈统一的嘶鸣/咆哮升流在环周约 0.3 秒内滚过，枪杆与刀高扬过一次，随后鼓点回到基线。远排只在白化雾墙中淡成剪影。

硬切 镜头 2 —— 6.0–8.5 秒 —— 怪物破环（THE MONSTER BREACH）〔WS 远景，14mm 超广角低机位，急推变焦过冲时荷兰角 +18° → -12°〕：从竞技场西南部地面级手持，镜头望向东北。Roco 位于画幅左下三分之一，仍保持预备姿势，第三具僵尸的飞灰云仍在他身旁飘散；画幅右侧三分之二与上三分之一是开阔竞技场与东侧环墙。约 6.4 秒东墙向内轰然迸裂——<<<1a2f4529-b84a-4109-ab06-51d53bd61402>>>1 从场外猛地撞破而入，以他的庞大身躯与融合武器肢破开尸线。三或四具僵尸被狠狠撞飞：一具抛向镜头左侧，一具被撞离地面、抛掷进竞技场，一具向前翻滚跌向 Roco；枪杆从亡者手中飞出，盔甲自冰面弹跳。Roco 的头猛地转向东。怪物清空尸线之际，摄像机 14mm → 50mm 在 0.2 秒内急推变焦到破环点，他的武器臂向前伸展，长骨金属刀刃末端位于其自然尖端（无手、无腕——这条肢体直接收窄融入刀身，形同一整条融合结构）。破环冲击处出现反应性镜头踩踏，画面被踹离轴 14 厘米，附带 4–5 次衰减副震荡吸收余震；急推变焦过冲时云台质量猛然把荷兰角从 +18° 甩到 -12°。雾深处远处橙色爆炸闪光短暂地以剪影勾勒出破环不之后的无尽尸潮。

本镜背景：东墙是被扰动的区段——僵尸被撞飞、脱手兵器磕落冰面、破环点有三或四具身体摊在雪地；它们身后，东线其余部分在怪物过境时短暂回缩，随后后排只前移足够让尸线回垂闭合。北、南、西三段环区都对破环做出反应，爆发一阵短暂更响亮的敲击升流——约 0.5 秒内兵器以双倍力度锤向胸甲、旗帜甩平、枪杆高扬、未亡之颚骤然开合、一圈统一的嘶吼咆哮滚过——随后回落进基线鼓点。外围骑兵把骸骨马首朝破环扬起，骨蹄更用力跺，骑手在头顶摇晃枪杆。
