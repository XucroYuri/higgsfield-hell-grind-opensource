从尸堆内部探针镜头(PROBE-LENS FROM INSIDE-THE-PILE)规则(对本提示的每个镜头均强制)：每个镜头都用一根微距探针镜头(MACRO PROBE LENS，Laowa 24mm 探针镜头式样——一根能伸进窄小空间的细长筒镜)伸入压在 Roco 身上的尸堆内部拍摄。镜头在僵尸躯体之间的缝隙中穿行，在层层札甲甲片之间、骨骸臂膀与晶体甲面之间穿行。摄影机永远栖居在尸堆内部——绝不在外，绝无远景定场，绝无广角。每个镜头都将镜筒顺着甲面(僵尸札甲或 Roco 的红色 <<<1d58fa3e-7359-4376-bb67-ea43d20c8fdb>>> 晶体)缓缓前推/侧滑/平移，躯体从画面四缘向内挤压。

从内部布光(LIGHTING-FROM-INSIDE)规则：尸堆内部几乎一片漆黑——密叠的僵尸躯体几乎挡尽了日光。唯一照到 Roco 的光，是透过躯体间窄缝渗进来的、稀少的细细光柱/明灭光点——惨灰的阴天光——惨白发灰的光束短暂横切过镜筒，照亮一个细节(一只收紧的骨手、一小片红色晶体、一缕干朽的肉条)半秒钟，随即尸堆移位、光束闭合。画面过半皆近乎全黑/深影，仅有细细的惨灰光影透切而过。外头暴风雪的光几乎看不见，只偶尔透过尸堆最长的缝隙，像远处一点黯淡的微光。

本提示的挤压/按压/堆压(SQUEEZE/PRESS/PILE)规则：本提示中绝无对 Roco 盔甲的击打——绝无枪戳、刀劈、武器冲击。威胁纯来自重量与压迫。压在 Roco 身上的 25 具僵尸以合力体重对他实施挤压与下压，随提示推进越收越紧、越压越重。全过程中，新增的僵尸持续从上方整个扑身/坠落砸下，以增加更多重量。

ROCO 竭尽全力挣扎规则(ROCO MAXIMUM-EFFORT STRUGGLE RULE，强制，每个镜头)：Roco 以绝对最大力气挣扎挣脱——每个镜头的每一秒皆是。慢镜头下，他铠躯内每块肌肉都在满负荷绷紧：胸口晶体随着缓慢暴烈的喘息剧烈起伏，双肩逆着重量向上猛扛，双臂向外撑出想推掉身上的躯体，手甲内的手指屈张成爪，去抓、去抠、去扯一切够得到的僵尸表面(骨臂、札甲甲片、破布)，腕部旋转想挣脱箍在身上的握抓，臀部弓起扭转想从底下滚出，双腿蹬踢对抗压腿的压制者，双脚抵住雪地想把整个身体撑起来。每个镜头都必须将挣扎呈现为巅峰用力——不是偶发、不是时断时续，而是持续而彻底。他倾尽一切。尸堆随每次上涌而脉动。但重量太沉——每一次竭力孤注一掷的上涌都告失败：一厘米红色晶体在缝隙中隆起，随即又被压平；一只骨手滑脱，随即更紧地重新扣死；一条腿挣脱了零点几秒，随即被三具新僵尸重新压住。Roco 从不停歇；尸堆则以更紧更重的挤压作为回应。每一镜头，观众都必须感受到他的竭尽全力撞上铺天盖地的重量。

慢镜头规则(SLOW-MOTION RULE)：本提示的每个镜头皆为慢镜头(4-6 倍慢放)。雪花在稀少的光缝间缓缓飘落；衣料与系绳缓缓起落；骨手以持续的压力缓缓收挤。

⚠⚠⚠ 第 0 帧运动(MOTION AT FRAME 0，至关重要——应用于每一帧，包括镜头 1 的第 0 帧)⚠⚠⚠ 自本提示每个镜头第 0 帧起便处于连续可见运动中——绝不冻结、绝不静止、绝无纹丝不动，哪怕只有一帧也不行。观众自最初一帧看到的便是：1. 每秒都有新亡灵武士加入。自第 0 帧起，从周围内圈不断有亡灵踏步迈进、奔冲上来、猛跃、或整个扑落到尸堆顶端。每一秒的每一镜头中，始终至少有一具新的僵尸正坠于半空或正落向尸堆——一条僵尸在第 0 帧扑落，一秒后另一条抵到，再两秒后又出现，如此连续不断。新到者可见地砸落在尸堆上、大字摊开、锁压到下方躯体上以增加重量。此点不容丝毫妥协：在每一镜头中，新增亡灵武士都清晰可见地从画外扑堆而上。2. 身处尸堆内的既有僵尸正主动移动以束缚内部囚徒。每一具已躺上尸堆的亡灵武士都处于连续可见运动中——它们并非直挺挺躺着，它们不是尸体。它们正拼命按压制服压在底下方的囚徒：胸甲甲片下胸廓起伏喘息，骨手屈张抓抠囚徒的盔甲与四肢，指尖滑脱便重新扣紧，双臂拧拽以摁住囚徒的手臂与双腿，躯体以全身之重前倾压迫囚徒，肩部挪移以重新分布体重。它们的动作读作一名摔跤手压制对手时的那种肌肉发力——恒定微观运动、恒定调整、恒定施压。3. 每当囚徒上涌便随之脉动与移位。埋在尸堆底部的囚徒正拼命挣脱(竭尽全力之猛冲)。每当他自下方猛冲，整个尸堆便短暂向外向上泛起涟漪——内躯体上移几厘米，然后僵尸们扣得更紧，这次猛冲被压平、尸堆往下压回。这一脉动-压回循环贯穿每个镜头清晰可见。4. 绝无静止的起始姿势。镜头并非从一个静止的尸堆、待其随后再动开始。尸堆在最初一帧便已处于全面运动中；摄影机是于运动中半途切入的。这四种行为在每一镜头的每一帧都必须清晰发生，包括最初那一帧。
