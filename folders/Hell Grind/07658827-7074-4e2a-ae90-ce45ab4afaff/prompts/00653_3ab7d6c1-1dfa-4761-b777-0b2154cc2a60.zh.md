摄影机（CAMERA）：实时的、手持的摇拍摄影机（LIVE handheld rig）——呼吸抖动（breath-jitter）、身体漂移（body-drift），永不稳定。一台主侧面摄影机（PRIMARY PROFILE CAMERA）采用广角镜头（18-24mm），保持在虫眼级地面高度、镜头高度约在雪面以上 40-60cm（武士的膝盖/大腿高度——远低于他们的髋部和头盔），锐利地向上倾斜（约仰起 50-70°），沿怪物左侧翼并行，镜头正对他的左中侧轮廓，从第 0 帧到最后一帧全程跟拍他自左向右横过屏幕。⚠️ 怪物取景（强制）：怪物只能被看到腰部以上或肩部以上——他的髋部和腿始终位于画面底缘之下。他的腰或胸口大致置于画面底缘；他的躯干/胸甲填满中间三分之一；他的头和骨刺肩部升入上三分之一，剪影衬在阴暗冒烟的阴云天空前。⚠️ 低角度上仰倾斜使怪物如巨人般凌驾（COLOSSUS）——观众透过向上的角度，以及画面上半部分戏剧性的「天空映衬皮肤」的对比来读出他的尺度。两旁的丧尸只作为裁切画面底缘的前景腿 / 髋 / 下躯干 / 武器柄出现（他们的头盔分别高出画面底缘，而怪物的髋部低于画面底缘）。观众立即可在直觉上、本能上读出该尺度——怪物凌驾在摄影机之上，就像一个巨人凌驾在一个孩童之上。摄影机匹配他的步速，在雪面附近以他的速度自左向右移动，每一次擦撞冲击都有镜头跺脚抖动（lens-stomp jolts）、阻尼摇晃、由他的肩部格挡摔来的歪斜镜头（dutch tilts）。摄影机在约 1-2m 范围内前后微微蜿蜒，所以我们有时从下方看到他的脸/有时从下方看到他的躯干/有时从下方看到他布满骨刺的脊背——但始终是他自地面仰视的左侧轮廓，被取景为腰部以上或肩部以上。

⚠️ 前景遮蔽物（FOREGROUND OCCLUDERS）每一帧都强制：附近的丧尸腿 / 靴子 / 髋 / 武器杆尾 / 旗杆底座 / 漆制护胫的剪影，不断在镜头前 0.3-1m 处横切画面底部，在他从它们身后经过时，滑插在摄影机和怪物之间。画面总是被近处的丧尸腿部分遮蔽，仿佛摄影机埋在雪里的丧尸腿部高度，透过人潮的缝隙拍摄。无硬切（NO HARD CUTS）。摄影机的路径是连续的。

0.0-1.5s —— 开场（OPENING）：摄影机在虫眼级地面高度、镜头位于雪面以上约 40-60cm（武士膝盖/大腿高度）处，与怪物左侧轮廓一起浮现，在广角镜头上锐利地向上（约仰起 50-70°）对准怪物；此时已在奔跑中段，怪物在画面自左向右移动。⚠️ 怪物被取景为腰部以上或肩部以上——他的髋和腿位于画面底缘之下，他的腰/胸口大致在画面底部，躯干填满中间三分之一，他的头 + 骨刺肩 + 顶髻填满上三分之一，剪影衬在阴暗冒烟的阴云天空前。两侧 170-180cm 的丧尸只作为低前景里的腿 / 髋 / 下躯干 / 武器柄裁切画面底缘（他们的头盔高于画面上缘）。他的脸位于上三分之一的侧面：自下方可见剥露颚部的笑容，凹陷的黄眼直视前方，发顶髻在脑后飘曳，肩上的骨刺承接上方透下的阴云灰白天光。他正处于强力的冲锋大步中，迈着吞噬地面的长步。⚠️ 在他前方，下一排丧尸在约 0.5s 内的慢动作 SLOW-MO 240FPS 中清晰地让开——同步的横向侧让、垂下武器、死去的颚部大张以示退避，在他迈步的前方开出一条走廊；播放在他逼近间隙时升回 60fps。头顶战旗在风中拍响。战鼓的节奏在四面八方咚咚敲响。

1.5-3.5s —— 第一次擦撞灰烬（FIRST DRIVE-BY ASH）：一名丧尸未能及时在他正前方让道。怪物不转弯，也不低头——他的左肩（靠近摄影机的一侧）在他跑过时，顺手（INCIDENTALLY）撞上丧尸的头盔/脸。⚡ 在接触点，播放降至 10000FPS 超慢动作，持续 0.4s——丧尸的躯体悬停于肩部接触之中，并从冲击处向外炸成黑色灰烬，一团冻结的暗干粒子云从头/胸腔喷发而出，兜鍪旋转着穿过云团，武士刀旋转，黑漆铠甲向外开裂。怪物的脸在露颚笑容中保持锁定朝前，从不看一眼这个击杀。播放升回 60fps；灰烬云雾在他继续迈步时飘过。摄影机保持侧面，接触时有镜头跺脚抖动。

3.5-5.5s —— 骑兵擦撞（人与马被抛离）：一名骑在扬起前腿的骨架马背上的亡灵骑手，进入怪物的走廊、位于他靠近摄影机的一侧（在他与镜头之间）。怪物没有减速——他径直跑过，他的左翼（LEFT FLANK）在路过时蹭过扬起前腿的马匹的胸口。⚡ 在接触时降至 10000FPS 超慢动作，持续 0.6s——死马被抬离马蹄、被横向抛出远离怪物（HURLED SIDEWAYS AWAY FROM THE MONSTER），肋骨和脊柱在半空中爆断分离，马头骨从颈上崩脱、在空中旋转，骑手在半空翻滚中以背朝方式被猛地拧离鞍座（TORQUED OFF），长枪首尾颠倒地旋转。⚠️ 马和骑手两者都在接触线上，于一个彼此重叠的暗粒子云中同时炸成黑色灰烬。播放升回 60fps。摄影机以侧面跟拍掠过正在四散的灰烬云雾。

5.5-6.5s —— 持续奔跑 + 让道（SUSTAINED RUN + PARTING）：摄影机在约 1.0s 的持续奔跑中保持侧面，与他并行。前方下一排丧尸在约 0.5s 内的慢动作 SLOW-MO 240FPS 中清晰地让开——像浪涛在高翘的船首前那样同步地侧移。战鼓节奏越来越响。怪物大步迈入一群稍密一些的丧尸之中——为中部节拍蓄势。6.5-9.0s —— ⚡⚡⚡ 中部节拍（THE MIDDLE BEAT）：丧尸头颅崩脱 + 跟焦（RACK FOCUS）拉到飞行的头部 + 摄影机跟踪该头部的空中飞行：

在 6.5s，一名正处怪物髋部高度路径上的丧尸，被他的步伐猛地击碎——怪物的左髋/肩在丧尸的上躯干处迎头撞上，将丧尸的颈骨撞断，并干净利落地把头颅从身体上完全切断。⚡ 在颈椎切断的瞬间（约 6.7s），播放跌入 10000FPS 超慢动作，并保持整整 2.0s 直到 8.7s——飞行的每一个细节都可一帧一帧地读出：
- 帧 A（FRAME A）——弹脱无阻（POP-FREE）：丧尸的躯干悬停于接触之中，兜鍪连头从颈部弹脱飞出（kabuto-and-head pop free）；断下的头（兜鍪仍系在其上）从怪物髋部的接触点开始它的抛物线飞行，朝着摄影机飞来。暗色灰烬像彗尾一样从断颈处拖曳而出。
- 帧 B（FRAME B）——跟焦拉动（RACK FOCUS PULL）：⚠️ 镜头以一次平滑的拉动完成跟焦（RACK-FOCUS）——焦点从中景处锐利的怪物剪影，转到飞行的断头上——怪物的脸/肩/庞大身躯在背景中变得柔和、失焦，而飞行中的兜鍪/头在它划过空中时，于前景/中景锁定到锐利如刀的焦点（PIN-SHARP focus）。观众的视线单凭焦点的转移，就被从怪物拽到飞行的头上。
- 帧 C（FRAME C）——摄影机跟踪那颗头：⚠️ 摄影机停止与怪物平行侧面跟踪，转而跟踪飞行头颅的弧线——镜头在慢动作中追随兜鍪的抛物线飞行，看它首尾颠倒地旋转掠过画面，死去的颚部在兜鍪内缘大张，兜鍪系带的飘带拖曳在身后，从断颈涌出的暗色灰烬在它后面喷出一条彗尾，暴风雪雪粒在慢动作中掠过，前景丧尸背甲的剪影在头颅从它们上方飞过时横切画面，飘带在其弹道后方拍响。头颅在其弧线上旋转约 3-4 圈，观众读出它飞行的每一个细节。
- 帧 D（FRAME D）——头颅甩过镜头（WHIPS PAST THE LENS）：⚠️ 飞行的头颅抵达镜头——兜鍪和头填满画面，在即将接触的最后一瞬间甩过摄影机左侧，死颚距镜头仅几厘米大张，骨制系带飘带拍打镜头边缘，灰烬喷雾在画面上散开。摄影机随着头颅甩过画面左侧并退出画面边缘，以一个硬质的镜头跺脚和歪斜镜头（dutch tilt）猛地一颤。
- 帧 E（FRAME E）——跟焦回到怪物（RACK FOCUS RETURNS TO MONSTER）：⚠️ 当头颅退出画面，镜头以一次平滑的拉动重新做跟焦——焦点从现已离开的头颅，转到怪物身上——怪物的剥露颚部面孔 / 肩膀 / 庞大躯体在中途大步中弹回锐利如刀的焦点，他露齿的笑容清晰可见，他的步伐仍在推进之中（他从未减速，从未看那颗头一眼，甚至从未察觉）。被斩首丧尸的残躯也在背景中可见，处于坍塌中途，正从断颈向下炸成黑色灰烬。播放升回慢动作 240fps，再在 9.0s 前升回 60fps 实时。怪物的脸以侧面轮廓保持锁定朝前——他从没看见，刚才那一大块差点掀掉摄影机的丧尸。

9.0-11.0s —— 强力肩部格挡擦撞（BIG SHOULDER-CHECK DRIVE-BY）：三名丧尸挤成一团紧簇，正挡在他的航道上，没能让开。怪物径直冲过他们——他的左肩 + 胸腔 + 髋部（靠近摄影机的一侧）在路过时撞上这团簇。⚡ 播放降到 10000FPS 超慢动作，持续 0.6s——三名丧尸全部悬停在接触线上，在怪物躯干周围呈扇形铺开，并且全部沿着接触线炸成黑色灰烬，三团彼此重叠的暗粒子云从胸甲/头盔喷发而出，黑漆铠甲向外开裂，兜鍪从头上旋转脱落，武器首尾颠倒地旋转。怪物的脸在侧面轮廓中保持朝前，步伐不受打断。播放升回 60fps；灰烬云雾从摄影机镜头前飘过。
